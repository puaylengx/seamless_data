Research Pipeline

ที่มาของแต่ละคอลัมน์ (Template Output)

คอลัมน์แหล่งที่มาประเภทการแปลง
rank Rank แปลง Normalize ตัวย่อ เช่น Asst.Prof → Asst.Prof., Assoc.Prof → Assoc.Prof.
group_rank Rank แปลง map: Academic Advisor และ Support Staff → ใช้ชื่อตรง, อื่นๆ ทั้งหมด → Lecturer
description Description copy คัดลอกตรง
division Division copy คัดลอกตรง
product_code Product Code copy คัดลอกตรง
firstname Firstname copy คัดลอกตรง
lastname Lastname copy คัดลอกตรง
title Title copy คัดลอกตรง
source Journal/Conference/Source copy คัดลอกตรง
national_international Other Classification + DB flags แปลง 1. ถ้า Classification เป็น Being used as public policy, Featured role International venue, หรือ Group/International → International
2. ถ้า Classification เป็น null → ดู DB flags: ถ้ามี flag นานาชาติใดเป็น 1 → International, ไม่มี → National
3. อื่นๆ → ใช้ค่าจาก Classification ตรงๆ
field Database (WoS, Scopus, TCI) parse ดึงข้อความหลัง Field: ในคอลัมน์ Database — เก็บเฉพาะส่วนที่ไม่ใช่ DB indicator
📅
Priority ของวันที่: ใช้ Online Date เป็นหลัก ถ้าว่างจึงใช้ Publication Date
คอลัมน์แหล่งที่มาประเภทการแปลง
publication_month Month → fallback Online/Publication Date แปลง ถ้า Month มีค่า:
 • รูปแบบ YYYY-MM → ดึงส่วน MM
 • ตัวเลขตรงๆ → แปลงเป็น int
ถ้าว่าง → ดึงเดือนจาก Online/Publication Date
publication_year Year แปลง ลบอักขระที่ไม่ใช่ตัวเลขออก (\D), แปลงเป็น Int64 (nullable), ค่าว่าง → NA
publication_calendar_year Year แปลง เหมือน publication_year — ใช้ปี ค.ศ. ตรงๆ
publication_budget_year Year + Month คำนวณ ถ้า publication_month >= 10 (ต.ค.–ธ.ค.) → ปีงบประมาณ = ปี + 1, ไม่เช่นนั้น = ปีเดิม
effective_date Online Date หรือ Publication Date แปลง รองรับหลายรูปแบบ:
 • "January 2024" → 2024-01-31 (วันสุดท้ายของเดือน)
 • วันที่ทั่วไป → YYYY-MM-DD
🔍
คอลัมน์เหล่านี้ parse มาจากข้อความใน Database (WoS, Scopus, TCI) เก็บเป็น flag 0 หรือ 1 (0 = ไม่อยู่ในฐานข้อมูลนั้น, 1 = อยู่)
คอลัมน์เงื่อนไขที่เป็น 1
WoS_with_JIF-P90ข้อความมี WoS และมี JIF ตามด้วยตัวเลข ≥ 90
WoS_with_JIFข้อความมี WoS และมีตัวเลข JIF (ทุกค่า)
WoS_SCมี WoS และ (SC)
WoS_SSมี WoS และ (SS)
WoS_AHมี WoS และ (AH)
WoS_ESมี WoS และ (ES)
Scopus_SJR-10มี Scopus SJR-10 หรือ Scimago rank ≤ 10% ของ total
Scopus_Q1มี Scopus และ SJR-Q1
Scopus_Q2มี Scopus และ SJR-Q2
Scopus_Q3มี Scopus และ SJR-Q3
Scopus_Q4มี Scopus และ SJR-Q4
Scopus_No_Qมี Scopus และ No_Q
SENSE_ABCมี SENSE
ERICมี ERIC
MathSciNetมี MathSciNet
Pubmedมี Pubmed
JSTORมี JSTOR
Project_Museมี ProjectMuse
Other_Inter.Databasesมี Other_Inter.Databases
TCI_Group1มี TCI (case-insensitive) และ group1 (ignore spaces)
TCI_Group2มี TCI (case-insensitive) และ group2 (ignore spaces)
National_Journalมี National และ Journal
⚠️
ข้อความใน Database (WoS, Scopus, TCI) ต้องใช้รูปแบบตามที่กำหนด เช่น WoS JIF90, Scopus SJR-Q1, TCI Group1 — ตัวสะกดผิดหรือ format ต่างออกไปจะทำให้ flag เป็น 0
🌱
parse มาจากคอลัมน์ SDGs Goal ซึ่งเป็น comma-separated list ของตัวเลข เช่น 3, 4.2, 13
คอลัมน์เงื่อนไขที่เป็น 1
sdg1มีเลข 1 (หรือ 1.x) ใน SDGs Goal
sdg2มีเลข 2
sdg3 – sdg16เช่นเดียวกัน (ตัวเลข 3–16)
sdg17มีเลข 17

ตัวเลขที่มีทศนิยม เช่น 4.2 → นับเฉพาะส่วนหน้า (4)  ·  ค่า null → ทุก sdg เป็น 0

Validation ก่อน Upload

รายการตรวจสอบเงื่อนไขผลถ้าไม่ผ่าน
