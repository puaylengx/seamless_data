# คำถามถึงฝ่ายการเงิน — ข้อมูล ERP 2025 และ Master Data (กันยายน 2026)

**จาก:** ทีม seamless_data (ระบบรวมข้อมูลการเงิน → dashboard) · **วันที่:** 2026-09-18 · **ผู้ประสานงาน:** Project Manager ทีม seamless_data

## ทำไมถึงถาม

ทีมกำลังนำไฟล์ **`clean_ERP_2025.xlsx`** (6,726 รายการ, วันที่เอกสาร 3 ต.ค. 2024 – 23 ก.ย. 2025) และไฟล์ **Master** ที่ได้รับ (Master_GL, Master_CostCtr, Master_IO_* ฯลฯ รุ่นวันที่ 2022-11-18 ถึง 2024-06-05) เข้าฐานข้อมูลกลางเพื่อทำ dashboard งบประมาณ ระหว่างตรวจสอบพบข้อมูลบางจุดที่**ทีมตัดสินใจเองไม่ได้** เพราะเป็นเรื่องความหมายทางบัญชี — จึงรวบรวมมาเป็นชุดเดียว **7 ข้อ** แบ่งตามความเร่งด่วน

**วิธีตอบ:** ตอบทีละข้อได้ ไม่ต้องรอครบ · ทุกข้อมี "ตัวเลือก" ให้ติ๊ก ถ้าคำตอบไม่อยู่ในตัวเลือกเขียนอธิบายได้เลย · เลขแถวที่อ้างคือ **เลขแถวใน Excel** (แถว 1 = หัวตาราง)
