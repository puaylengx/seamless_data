Database Connection

การเชื่อมต่อฐานข้อมูล PostgreSQL รองรับ 2 modes: SSH Tunnel และ Direct

Overview

SSH Tunnel

  • เชื่อมต่อผ่าน SSH server ก่อน
  • DB อยู่ใน private network
  • รองรับ password และ private key
  • ตั้งค่า DB_CONNECTION_MODE=ssh

Direct

  • เชื่อมต่อ DB โดยตรง
  • DB เข้าถึงได้จากเครื่อง local
  • ไม่ต้องการ SSH credentials
  • ตั้งค่า DB_CONNECTION_MODE=direct

Environment Variables

ตัวแปรหลัก

VariableDefaultหมายเหตุ
DB_CONNECTION_MODE ssh โหมดการเชื่อมต่อ: ssh หรือ direct required
DB_NAME ic_finance ชื่อฐานข้อมูล required
DB_USERNAME — ชื่อผู้ใช้ PostgreSQL required
DB_PASSWORD — รหัสผ่าน PostgreSQL required
DB_HOST localhost SSH: host ของ DB ที่มองจาก SSH server / Direct: host จริง optional
DB_PORT 5432 port ของ PostgreSQL optional

SSH Tunnel ssh mode เท่านั้น

VariableDefaultหมายเหตุ
SSH_HOST 192.168.64.2 IP หรือ hostname ของ SSH server required
SSH_PORT 22 port ของ SSH server optional
SSH_USERNAME — ชื่อผู้ใช้ SSH required
SSH_PASSWORD — รหัสผ่าน SSH (ถ้าไม่ใช้ key) optional
SSH_PKEY — path ของ private key (ถ้าใช้ key auth) optional
SSH_PKEY_PASSWORD — passphrase ของ private key optional

Connection Tuning

VariableDefaultหมายเหตุ
DB_CONNECT_TIMEOUT10timeout (วินาที) ในการเชื่อมต่อ
DB_APP_NAMEpython-clientapplication name ที่แสดงใน pg_stat_activity
DB_KEEPALIVES_IDLE30วินาทีก่อนส่ง keepalive แรก
DB_KEEPALIVES_INTERVAL10ระยะห่างระหว่าง keepalive
DB_KEEPALIVES_COUNT5จำนวนครั้งสูงสุดก่อน drop connection

Setup

1. คัดลอก .env template

cp .env.example .env

2. แก้ไข .env — SSH mode

# .env
DB_CONNECTION_MODE=ssh

SSH_HOST=192.168.64.2
SSH_PORT=22
SSH_USERNAME=your_user
SSH_PASSWORD=your_password

DB_HOST=localhost
DB_PORT=5432
DB_NAME=ic_finance
DB_USERNAME=db_user
DB_PASSWORD=db_password

2. แก้ไข .env — Direct mode

# .env
DB_CONNECTION_MODE=direct

DB_HOST=db.example.com
DB_PORT=5432
DB_NAME=ic_finance
DB_USERNAME=db_user
DB_PASSWORD=db_password

3. ทดสอบการเชื่อมต่อ

python tests/test_connection.py

Usage

แบบ context manager (แนะนำ)

from helpers.connect_db import db_session

with db_session() as (conn, tunnel):
    with conn.cursor() as cur:
        cur.execute("SELECT * FROM erp_2025 LIMIT 10")
        rows = cur.fetchall()
# commit และ close อัตโนมัติ

แบบ manual

from helpers.connect_db import connect_to_db, close_connection

conn, tunnel = connect_to_db()          # ใช้ DB_NAME จาก .env
# หรือระบุชื่อ DB โดยตรง
conn, tunnel = connect_to_db("ic_finance")

try:
    with conn.cursor() as cur:
        cur.execute("INSERT INTO erp_2025 (...) VALUES (...)")
    conn.commit()
except Exception:
    conn.rollback()
    raise
finally:
    close_connection(conn, tunnel)

File Structure

├── helpers/
│   └── connect_db/
│       ├── __init__.py         # export: connect_to_db, close_connection, db_session
│       └── connection.py       # SSH + direct logic
├── tests/
│   └── test_connection.py      # ทดสอบการเชื่อมต่อ

├── .env.example                # template
└── requirements.txt
⚠️
ห้าม commit ไฟล์ .env — เพิ่ม .env เข้า .gitignore เสมอ เพราะมี credentials จริง
ℹ️
paramiko version — pin ไว้ที่ <3.0.0 เพราะ sshtunnel ยังไม่รองรับ paramiko 3.x (ซึ่งลบ DSSKey ออก)
💡
tunnel เป็น None เสมอเมื่อใช้ direct mode — close_connection(conn, tunnel) จัดการ None ได้โดยอัตโนมัติ ไม่ต้องเช็คเอง
